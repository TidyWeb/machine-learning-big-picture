# Machine learning: the big picture

### [Visit the live site ↗](https://tidyweb.github.io/machine-learning-big-picture/)


A standalone, visual overview of machine-learning ideas and workflows, from examples, features and labels through supervised models, evaluation, neural networks and clustering.

## Open the guide

Open [`index.html`](index.html) in a browser, or visit the published guide:

<https://tidyweb.github.io/machine-learning-big-picture/>

The `assets/` folder contains the logo and locally served fonts used by the page. Font license texts are included beside the font files.

Examples and house-sale values in the guide are illustrative. See the Sources and scope section in the guide for its references.
